# Archived GxE development diagnostics

The JSON and profiling files in this directory are retained only as historical
numerical diagnostics. They are not current workflow specifications, accepted
artifact examples, or compatibility fixtures.

The development status reports that previously accompanied them were removed
because they described retired cache/shard workflows, legacy artifact readers,
hash compatibility checks, noncanonical feature-mode aliases, and superseded
genotype-pass counts.

For the current implementation contract, use:

- `AGENTS.md` for the definitive reference-estimation versus inference
  jackknife boundary;
- `README.md` and `docs/gxe_genie.md` for the supported non-general GxE CLI;
- `docs/generalized_gxe_variant_ldscore_contract.md` for generalized GxE; and
- `docs/architecture/ADR-generalized-gxe-variant-ldscore.md` for the estimator
  design decision.
