# Benchmark records

The user-facing results and reproduction commands are in
[Benchmarks](../docs/wiki/Benchmarks.md). These directories retain historical
machine-readable timings and numerical diagnostics, including failed experiments.
Use the current guides for analysis commands.

The [PCGC release validation](pcgc_development/pcgc_release_validation.md) describes the
aggregate calibration tables in `pcgc_release_20260927/`. These contain
bias, SE calibration, and coverage for the simulated settings.

Development records for PCGC and mixture prediction are in
`pcgc_development/` and `prediction_development/`. They retain the original
experiments and implementation history; their commands may describe earlier
versions. Use the user guides for current behavior and options.
