# Contextual native estimator — Stage 2 report

## Decision

`NARROW_GO` for Stage 3, restricted to extending the same descriptor-owned
internal executor and its differential fixtures.

The streamed BED source scores, raw actions, and full fixed-probe Gram match
the active Python oracle and the frozen Stage 1 executor for generated `Q=1..4`
cases, both counted-allele orientations, explicit missing calls, strict and
generic annotations, explicit and counter probes, and every tested tile plan.
Descriptor ownership, scale identity, pass/call ledgers, phase mutation checks,
and all seven Stage 2 protected operations are executable and fail closed in
the focused test envelope. Legacy bindings and defaults are unchanged.

This is not a full or production Stage 2 GO. Stage 3 may add grouped reference
and same-person work behind this internal boundary, but may not publish a
reference artifact or claim tabla admission, measured peak memory, NUMA
ownership, adversarial file immutability, complete protected-call audit
records, or production performance. Those claims remain blocked by the exact
items in **Remaining risks/blockers**.

## Scope completed

### Descriptor-owned incomplete reference executor

- Added `summit::context_v1::ContextualReferenceExecutorV1` in a same-
  translation-unit include beside the Stage 1 differential executor. The only
  edit to `gxeldcore.cpp` is one include and one additive binding call.
- Duplicated BED/BIM/FAM descriptors with `CLOEXEC`, recorded file metadata,
  parsed BIM/FAM structure, and owned arbitrary retained sample and variant
  maps, expected variant IDs/alleles, per-variant counted-allele orientation,
  affine means/inverse scales, annotations, groups, names, bases, probes, and
  execution policy.
- Implemented SNP-major PLINK decoding for A1 dosage codes `2/1/0`, optional
  A2 conversion, and the sealed affine transform
  `(counted dosage - mean) * inverse_scale`. Missing calls map to the sealed
  mean and therefore exactly zero after scaling. Expected per-variant missing
  counts and a variant-major retained missingness identity are checked in both
  descriptor passes.
- Recomputed and required the active `sealed_variant_affine_v1` plan identity,
  retained-order digest, affine-vector digests, exact BIM IDs/alleles, and
  closed scale/missingness policy strings before the first decode.
- Accepted exact explicit Rademacher probes or per-probe NumPy-Philox keys.
  Counter probes are generated by global probe index, independent of block,
  tile, thread, or fresh-process schedule.
- Implemented the source pass, generic weighted and strict routed target
  passes, projected raw actions, and the annotation-mass-unnormalized,
  probe-averaged raw Gram `(1/B_T) sum_b A_raw,b^T A_raw,b`. Source scores
  `[M,Q,B_T]` and raw actions `[N,C,B_T]` remain native-resident for Stage 3.
- Returned only compact read-only owned NumPy arrays, canonical pair/component
  maps, scale/probe identities, diagnostics, admission, and telemetry. The
  result is explicitly `complete_reference_artifact=false`. A constructor-
  gated `differential_snapshot()` returns defensive copies of wide internal
  panels for tests only.
- Implemented physical variant, probe-resident, probe, action, annotation, and
  context tiling. Each probe-resident batch performs one source and one action
  descriptor traversal. Strict mode seals one annotation ID per variant and
  omits zero-weight target work.

### Protected execution and lifecycle

- Routed all wide Stage 2 work through seven semantic operations:
  `sample_probe_projection_tn`, `sample_probe_projection_nn`, `source_tn`,
  `full_target_nn`, `action_projection_tn`, `action_projection_nn`, and
  `action_gram_tn`. No grouped, same-person, trait, `DirectContext`, Mailman,
  or legacy X/W scientific path is called.
- Used the established allocation-free deterministic tiled NN/TN kernels as
  primary operations, an output-entry-major scalar witness, and an
  independently loop-ordered reduction-major scalar fallback. Retry,
  fallback, canary, finiteness, operand, runtime-thread/affinity, and witness
  checks all use pre-admitted buffers.
- Required fault injection to name both a semantic operation and a stable
  global point anchor. Point containment selects the same logical work under
  different tilings; unmatched selectors fail before publication.
- Preallocated all large execution and integrity vectors before the first
  decode, admitted a checked fixed-capacity event vector, reconciled exact
  expected/observed semantic calls, and released execution scratch before
  compact publication.
- Chained immutable input, source, source/action, and final-output fingerprints
  across `post_seal`, `post_admission`, `post_source`, `post_action`,
  `pre_finalization`, and `pre_publication`. Publication now rechecks files,
  inputs, and outputs at entry and exit.
- At every checkpoint, file evidence is sealed dev/inode/size/nlink/mtime/ctime
  plus allocation-free first/last-4-KiB FNV-64 boundary samples, bracketed by
  metadata checks. This is supplemental boundary evidence, not a full-file
  content digest or OS-enforced immutable lease.

## Performance and admission

The only timing evidence is a reproducible small-fixture smoke benchmark. It
is useful for plan/call reconciliation, not for tabla throughput or scaling.

- Dimensions: `N=13`, `M=11`, `Q=4`, `K=2`, `C=20`, `B_T=5`, fp64,
  one decode thread and one protected-GEMM thread; 15 fresh executors per plan.
- Full plan (`V=11`, resident/tile probes 5, actions 20, annotations 2,
  contexts 4): median constructor 0.266 ms; median run 1.012 ms
  (0.905–1.917 ms); 2 descriptor passes, 2 decoded blocks, 22 variant visits,
  7 protected calls.
- Tiled plan (`V=3`, resident 3, probe tile 2, action 3, annotation 1,
  context 2): median constructor 0.220 ms; median run 2.367 ms
  (2.329–2.731 ms); 4 descriptor passes, 16 decoded blocks, 44 variant visits,
  122 protected calls.
- Full-plan tracked threshold: 148,086 bytes = 21,083 permanent + 63,835
  shared source/action arena + 42,112 integrity + 6,976 compact + 14,080
  telemetry bytes; required telemetry capacity 88.
- Tiled tracked threshold: 218,782 bytes = 21,083 permanent + 16,131 shared
  source/action arena + 13,312 integrity + 6,976 compact + 161,280 telemetry
  bytes; required telemetry capacity 1,008. The smaller panels are outweighed
  by the deliberately conservative per-call event reserve in this tiny case.
- `required_workspace_bytes` is a checked tracked-vector-payload threshold,
  not measured RSS or an allocator-enforced process peak. The published
  `tracked_high_water_bytes` is the planned upper bound, not an observation.
- No phase elapsed times, physical BED read/page-fault metrics, process RSS,
  NUMA page placement, remote-access counters, B=128/B=1024 ladder, or tabla-
  scale throughput was measured.
- The only accepted policy is unbound standard allocation with output node
  `-1`; the result truthfully reports `numa_applicable=false` and
  `numa_verified=false`. This host has eight NUMA nodes, so absence of a claim
  is not NUMA qualification.

## Remaining risks/blockers

1. **Admission is not an exact actual-peak contract.**
   `ContextualReferenceExecutorV1::build_preflight` accounts named vector
   payloads and phase live ranges, integrity buffers, compact arrays, and the
   event vector with checked arithmetic. It excludes allocator/vector object
   overhead, M-scale string objects/payloads, transient full BIM parsing,
   mmap/RSS, OpenMP runtime allocations, Python dictionaries/event objects,
   and explicit safety headroom. Plan inputs and BIM/FAM metadata are also
   copied before cap rejection. Consequence: exact/cap-minus-one proves the
   tracked threshold, not process-memory admission. Full GO requires an
   allocator/arena-enforced live-range model, construction preflight, measured
   phase high-water reconciliation, and exact/minus-one recovery tests. The
   focused suite also lacks a synthetic overflow case for every individual
   dimension product and a measured repeated-construction/destruction leak
   test; both remain required lifecycle evidence.
2. **File mutation evidence is not adversarial immutability.**
   `fingerprint_file_samples` covers only the first/last 4 KiB, while metadata
   provides the ordinary full-file change sentinel. Tests deliberately mutate
   sampled BED/BIM/FAM bytes. Publication rechecks at entry and exit, but no
   userspace check eliminates the final check-to-return race against an
   adversarial writer. Full GO needs a declared full-content/retained-content
   identity policy plus an OS-enforced immutable snapshot, lease, or equivalent
   ownership contract.
3. **NUMA ownership is unimplemented.** The executor rejects bound/output-node
   policies and reports no placement evidence. Stage 3 production work must
   allocate/first-touch admitted arenas on the selected node, attest pages and
   affinity, and test one- and two-socket/process plans.
4. **Protected telemetry and run provenance are incomplete.** Events contain
   semantic ranges, dimensions, strides, transpose, attempt, and resolution,
   but not elapsed time, exact operand/runtime fingerprints, checksum/witness/
   canary values, timestamps, process/slot identity, or a canonical digest.
   The compact result also omits binary hash, dirty state, compiler flags, ISA,
   OpenMP/BLAS identity, and complete descriptor/map/group digests. Add and
   schema-freeze those fields before production inheritance.
5. **Realistic performance evidence is absent.** The microbenchmark above is
   a correctness fixture. No synthetic smoke/medium/large ladder, B=128/1024,
   physical I/O, page-fault, RSS, protected-operation throughput, or NUMA
   comparison has run. Stage 3 may use the code for science development but
   may not infer tabla capacity or speed from these timings.
6. **The result is intentionally incomplete.** Grouped numerators, signed
   same-person U-statistic, deletion systems, schema manifest, and complete
   native reference artifact remain Stage 3 scope. The wide differential
   snapshot is test-only and must never become a public artifact field.
